# Parallel evolution under constraint shapes echinocandin resistance in *Candida auris*

Nicholas C. Cauldron, Erika N. Dort, Garrett M. Weeks, P. David Rogers, Christina A. Cuomo

Code repository for population genomic analysis of *FKS* genes in *C. auris*

* `scripts/`: Python and R scripts used to calculate selection statistics 
* `docs/`: Further documentation on usage of generalizable scripts
* `codeml_ctrls`: Exemplar control files used to run CODEML.
* `GWAS_sample_metadata.tsv`: Metadata for samples used in GWAS (n=681).
